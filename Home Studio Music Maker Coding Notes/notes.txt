  1. src/audio/audioEngine.js — The Sound Engine (1,001 lines)

  This is the brain of your app. It's a single shared audio system (called a
  "singleton") that every feature plugs into.

  What it does:
  - getCtx() — creates one AudioContext (the browser's audio system) that the
  whole app shares
  - playDrum(type, velocity) — synthesizes 12 different drum sounds (Kick, Snare,
   Hi-Hats, Clap, Toms, Perc, FX) entirely from math — no samples needed
  - startRecording() / stopRecording() — handles your microphone and saves takes
  - detectBpm(file) — analyzes any audio file and figures out the tempo
  - Master FX chain — Reverb → Delay → Compressor → Distortion → EQ that applies
  to all drum/synth sounds at once
  - Mastering chain — a professional-grade signal path: Transient Shaper →
  Multiband Compressor → Stereo Imager → Limiter → LUFS Analyzer, wired in after
  the FX chain
  - bufferToMp3Blob() — exports audio as an MP3 file using the lamejs library
  - bufferToWavBlob() — exports as WAV

  work survives page refreshes.

  3. src/App.jsx — The Shell (341 lines)

  This is what you see on screen — the tab bar at the top and the content area
  below.

  The keep-alive system (what we fixed last session):
  mountedTabs = Set of all tabs ever clicked
  → First click on a tab: mounts the component for the first time
  → Later clicks: just CSS display:block/none — component stays alive
  This means Auto-Tune can be running, you switch to Vocal Removal, and both keep
   working simultaneously.
